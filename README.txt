AI圆桌 — 多智能体协同讨论与决策平台
=====================================

压缩包内容说明
--------------

1. index.html          (2.3MB)  应用主体，单文件零依赖，双击即用
2. 启动AI圆桌.bat       (2KB)    一键启动脚本（推荐，完整功能，需Python 3.8+）
3. ocr_server.py        (31KB)   后端服务（语音朗读/OCR识别/联网搜索等附属功能）
4. assets/              (36MB)   精灵角色素材
   ├── sprites/         5色精灵×7状态 + 总负责人×4状态 = 39张PNG
   │   ├── blue/        青云（深海之灵）- 理性分析
   │   ├── orange/      赤焰（太阳之灵）- 创新突破
   │   ├── green/       翠灵（丛林之灵）- 务实执行
   │   ├── purple/      紫星（星矿之灵）- 系统架构
   │   ├── pink/        粉光（云花之灵）- 共情协调
   │   └── manager/     总负责人（扩展模式）
   └── spirits/         5张精灵起源故事插画(JPG)
5. docs/                (1.4MB)  架构文档
   ├── png/             8张架构图PNG
   └── svg/             8张架构图SVG（分层架构/协作引擎/辩论触发/记忆系统/检查点状态机/模块依赖/数据流/评判融合）
6. 初赛Demo帖内容.md    Demo帖内容模板
7. README.txt           本说明文件


快速开始
--------

方式一：一键启动（推荐，完整功能）
  1. 解压本zip文件
  2. 双击「启动AI圆桌.bat」
  3. 浏览器自动打开，即可使用全部功能
  > 需要安装 Python 3.8+（下载地址：python.org）

方式二：直接双击HTML（核心功能）
  1. 解压后双击 index.html 用浏览器打开
  2. 核心讨论功能完全可用
  3. 顶部会显示橙色提示条，语音朗读/OCR/联网搜索等附属功能不可用
  > 如需完整功能，请使用方式一

使用步骤
--------
1. 启动后点击右上角"设置"按钮，配置任意一家大模型的API地址和密钥
   （支持豆包/DeepSeek/通义千问/Kimi/智谱清言/文心一言/讯飞星火/MiniMax）
2. 在顶部输入框输入议题，选择团队，点击"开始"
3. 试试智能触发：输入#引用知识库 / 输入/调用技能 / 输入@选择协作模式
4. 自建阵容：点击左侧"添加精灵"或"自建团队"组装专属专家团
5. 管理技能：点击左侧"技能"按钮查看16个内置技能，或用AI一键生成


技术特征
--------
- 17个源文件 → build.py合并为单HTML (2.3MB)
- 约15,700行代码，400+方法
- 纯前端零依赖部署，数据存储在浏览器本地
- PBKDF2密码哈希 + AES-GCM密钥加密
- IndexedDB + localStorage双层存储 + CompressionStream gzip压缩
